## 📌 Overview
**Nexora E-Cell** is the official digital portal for the Entrepreneurship Cell. It serves as the central hub connecting aspiring student entrepreneurs with industry mentors, angel investors, incubation resources, and hackathons. Engineered with a bold futuristic cyber-aesthetic, high-performance micro-interactions, dynamic event registration flows, and edge-cached deployment on Vercel.

---

## ⚠️ Problem Statement
Campus entrepreneurship ecosystems often struggle with engagement and fragmented resource distribution:
- **Disjointed Event Discovery:** Students miss out on hackathons, pitch fests, and grant opportunities due to scattered communication channels (WhatsApp groups, posters, unindexed emails).
- **High Friction Incubation Onboarding:** Early-stage campus startups lack a streamlined digital channel to submit pitch decks, request faculty mentorship, or access prototyping labs.
- **Uninspiring Digital Presence:** Generic academic department templates fail to reflect the high-energy, disruptive nature of modern startup culture.

**Nexora E-Cell** solves this by establishing a unified, community-driven digital platform featuring streamlined event registrations, incubation tracking, and speaker showcases.

---

## 🛠️ Technology Stack & Architecture
- **Frontend Architecture:** Semantic HTML5, CSS3 (Custom Glassmorphism Design System, CSS Grid, Flexbox, Keyframe Animations), Vanilla ES6+ JavaScript.
- **Deployment & Edge Infrastructure:** Vercel Global Edge Network with instant cache invalidation and continuous Git deployments.
- **Interactive Modules:** Smooth scroll navigation, dynamic modal dialogs, real-time form validation, and reactive event filter engines.

---

## 🌟 Key Features
1. **Dynamic Event Hub:** Comprehensive showcase for upcoming entrepreneurship summits, ideation workshops, and investor pitch sessions.
2. **Startup Incubation Gateway:** Simple multi-step application portal for student founders seeking seed funding, legal guidance, and cloud credits.
3. **Speaker & Mentor Gallery:** High-impact profiles highlighting visiting venture capitalists, successful startup alumni, and keynote speakers.
4. **Interactive Timeline & Milestones:** Chronological tracking of past cohort achievements, funding rounds raised, and hackathon victories.
5. **Mobile-First Responsive Layout:** Fluid, adaptive layout tested across smartphones, tablets, laptops, and ultra-wide displays.

## ⚡ Quick Start & Local Setup

### Prerequisites
- Modern Web Browser (Google Chrome, Microsoft Edge, Mozilla Firefox)
- Optional: Node.js (for Vercel CLI) or Python (for local server)

### 1. Clone the Repository
```bash
git clone https://github.com/prajwalsharma08/nexora-ecell-website.git
cd nexora-ecell-website
```

### 2. Run Locally
Using Python's built-in HTTP server:
```bash
python -m http.server 8000
```
Open **`http://localhost:8000`** in your browser.

Or using the Vercel CLI:
```bash
npm install -g vercel
vercel dev
```
