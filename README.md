## 🔤 What Does "Nexora E-Cell" Mean?

| Word | Origin | Meaning in This Context |
|------|--------|------------------------|
| **Nexora** | Latin *nexus* — connection, bridge to the future | Connecting student innovators, venture funds, and industry leaders |
| **E-Cell** | Abbreviation — Entrepreneurship Cell | Student-driven innovation cell fostering startup culture |

---

## 🚀 Key Features

- 🎯 **Event & Hackathon Hub**: Seamless registration for pitch competitions and startup summits.
- 💡 **Startup Showcase**: Spotlight directory for student-led ventures and incubator projects.
- 🤝 **Mentor Network**: Integrated booking system for 1-on-1 founder mentorship sessions.
- 🎨 **Modern Cyber-Dark UI**: High performance, zero-lag design deployed live on Vercel.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Modern CSS3 (CSS Grid/Flexbox, Variables), ES6 JavaScript
- **Hosting**: Vercel Global Edge Network
